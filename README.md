# FractalGrid

A dynamic, ultrawide-optimized tiling engine for KWin.

FractalGrid exposes a set of powerful, ergonomic shortcuts and a smart geometric layout engine that makes window management on ultrawide and high-resolution monitors effortless.
e

It lives between:

* KDE’s default floating-window behavior, and
* a full tiling window manager.

## Upstream Fork

Inspired and based on the original UltrawideWindows project by lucmos:
https://github.com/lucmos/UltrawideWindows

This project retains the high-level idea but replaces the geometry engine with a fully composable layout generator.

## Usage

### Installation

```bash
$ git clone git@github.com:TGPSKI/FractalGrid.git
$ cd FractalGrid
$ ./scripts/update.sh
```

### Update

```bash
$ cd FractalGrid
$ ./scripts/update.sh
```

### Remove

```bash
$ cd FractalGrid
$ ./scripts/uninstall.sh
```
